# 페르소나 검수 지침

## 무엇을 하는가

이 도구에 나오는 인물들은 **서울 문화향유 조사 통계를 바탕으로 컴퓨터가 만든 가상 인물**입니다. 실제 사람이 아닙니다. 각 인물은 두 부분으로 되어 있습니다.

- **앵커**: 성별, 연령대, 사는 생활권, 학력, 직업, 소득, 지난 1년간 관람한 장르 같은 **정해진 사실**
- **서사**: 그 사실을 바탕으로 쓴 **12개 항목의 글** (주말 일과, 문화 취향, 장벽 등)

여러분은 **서사가 앵커와 맞는지, 한 사람의 이야기로 읽히는지, 자연스러운 한국어인지**를 판단합니다.

## 가장 중요한 규칙

- **혼자 판단합니다.** 채점이 모두 끝날 때까지 다른 평가자와 문항 내용을 이야기하지 않습니다. 궁금한 점은 이 지침서를 기준으로 판단하고, 지침서에 없는 문제는 메모 칸에 적어 두세요.
- **찾아보지 않습니다.** 인터넷 검색이나 다른 자료 없이, 읽은 그대로 판단합니다.
- **읽은 대로 고릅니다.** 평가자의 판단을 채점하는 시험이 아닙니다. 다만 한 문항 한 문항을 꼼꼼히 읽어 주세요 — 대충 넘긴 판단은 결과를 흐립니다.
- **화면과 코드를 나누지 않습니다.** 접속 코드, 화면 캡처, 문항 내용을 다른 평가자를 포함해 누구에게도 보여주지 않습니다.
- **지치면 쉬세요.** 한 번에 1시간 이상 이어서 하지 않는 것을 권합니다. 저장은 문항마다 자동으로 됩니다.

## 한 문항의 순서

### 1단계 — 가린 글을 보고 추측하기

먼저 서사만 보여줍니다. 이름·나이·동네처럼 **정답을 그대로 드러내는 단어는 ○○로 가려져** 있습니다. 글만 읽고 두 가지를 추측해 고르세요.

- 이 사람의 **연령대**
- 지난 1년간 영화·공연·전시·축제 등을 **현장(오프라인)에서 관람했는지** (영화관에서 본 영화도 관람입니다)

모르겠으면 **가장 그럴듯한 것**을 고르세요. 답을 비워둘 수는 없습니다. 2단계로 넘어가면 1단계로 돌아갈 수 없습니다.

### 2단계 — 앵커와 함께 채점하기

이제 앵커(정해진 사실)와 가리지 않은 서사 전체가 함께 나옵니다. 다섯 가지를 판단합니다.

## 1. 모순이 있는가

**모순**이란 서사가 앵커와 **양립할 수 없는 사실**을 말하는 것입니다. 판단 기준은 하나입니다:
**서사를 합리적으로 읽었을 때, 서사와 앵커가 둘 다 참일 수 없는가?** 둘 다 참일 수 있으면 모순이 아닙니다.

모순인 예:

- 앵커는 "지난 1년 관람 안 함"인데 서사는 "지난달 뮤지컬을 보러 갔다"
- 앵커는 "40대"인데 서사는 "고등학생으로 방과 후에"
- 앵커의 관람 장르에 연극이 없는데 서사는 "올해 연극을 세 편 봤다"
- 앵커는 "혼자 관람"인데 서사는 "늘 가족과 함께 관람한다"

모순이 **아닌** 예:

- 앵커에 있는 사실을 서사가 **언급하지 않음** — 빠진 것은 모순이 아닙니다.
- 앵커와 **어울리지 않아 보이지만 가능한** 내용 — 70대가 유튜브를 즐겨 본다, 저소득층이 가끔 비싼 공연을 본다 등
- 과거 이야기 — "젊었을 때는 연극을 자주 봤다"는 지난 1년 관람 여부와 모순이 아닙니다.
- 관람하지 않은 장르에 **관심이 있다**고 말하는 것 — 관심과 관람은 다릅니다.
- **어조·인상** — "나이에 비해 젊게 느껴진다" 같은 느낌은 모순이 아닙니다. 서사가 **말한 사실**만 봅니다.

### 헷갈리기 쉬운 경우

| 경우 | 판단 |
|---|---|
| 앵커는 관람 안 함인데 서사는 **유튜브·OTT로 공연 영상을 본다** | 모순 아님 — 온라인·스트리밍 시청은 **현장(오프라인) 관람이 아닙니다** |
| 앵커는 관람함(예: 극장 영화)인데 서사는 **영화관에 간다**고만 한다 | 모순 아님 — 영화관 관람도 관람입니다 |
| "지난 1년"의 기준 | 조사 시점부터 **최근 1년**. "예전에", "젊었을 때", "몇 년 전"은 과거 이야기라 모순 아님. "올해", "최근에", "지난달"은 지난 1년입니다 |
| 앵커는 가족과 관람인데 서사는 "**가끔** 친구와도 간다" | 모순 아님 — 앵커는 **주로** 함께하는 사람입니다. "늘 혼자만 간다"처럼 앵커를 부정하면 모순 |
| 앵커 가구원 수는 1명인데 서사는 "**아내·두 자녀와 함께 산다**" | **모순** — 숫자가 안 나와도 읽으면 알 수 있는 모순(추론 모순)도 모순입니다 |
| 앵커 가구원 수는 1명인데 서사는 "**따로 사는** 자녀가 가끔 들른다" | 모순 아님 — 함께 살지 않는 가족입니다 |
| 앵커 여가 동반자(혼자)와 관람 동반자(가족)가 다르다 | 모순 아님 — 앵커가 원래 둘을 다르게 줄 수 있습니다. 서사가 이 둘을 구분해 쓰면 정상입니다 |
| 관람비·소득을 "**넉넉지 않다**", "부담된다"처럼 느낌으로만 말한다 | 앵커 구간과 **숫자·수준이 어긋날 때만** 모순. 느낌 표현은 모순 아님 |
| 직업·학력 | 앵커가 무직/은퇴인데 서사가 "평일에 회사에 출근한다"면 **모순** |

**장르 대응** (관람 장르 판단에 씁니다)

| 서사에 나온 말 | 앵커의 장르 |
|---|---|
| 영화관, 극장에서 영화 | 극장 영화 |
| 미술관, 갤러리, 전시회 | 미술관·전시회 |
| 박물관, 역사관 | 박물관 |
| 가수 콘서트, 대중음악 공연, 음악 페스티벌 | 대중공연 |
| 연극, 뮤지컬 | 연극(뮤지컬 포함) |
| 클래식 음악회, 오페라, 교향악 | 서양 고전 음악공연 |
| 국악, 판소리, 전통 공연 | 전통예술공연 |
| 발레, 현대무용 | 무용공연 |
| 북토크, 낭독회, 작가와의 만남 | 문학행사 |
| 지역 축제, 거리 공연, 야외 행사 | 야외문화행사 |

모순이 있으면 **어느 항목**에 있는지 고르고(왼쪽 서사에서 문단을 누릅니다), **근거가 되는 문장을 그대로 옮겨** 적습니다.

## 2. 앵커 부합 (1–5)

| 점수 | 기준 |
|---|---|
| 5 | 앵커와 어긋나는 내용이 전혀 없다 |
| 4 | 어긋난다고 하기엔 애매한 표현이 한 곳 있다 |
| 3 | 사소한 불일치가 한 곳 있다 — **모순까지는 아닌** 수치·빈도의 작은 차이 (예: 관람 횟수 구간과 서술된 빈도가 조금 다름) |
| 2 | 명백한 모순이 한 곳 있다 |
| 1 | 명백한 모순이 두 곳 이상 있다 |

**「곳」은 서로 다른 앵커 항목 단위로 셉니다.** 같은 사실(예: 관람 여부)이 여러 문단에 되풀이되면 한 곳입니다.
모순과 사소한 불일치가 함께 있으면 모순을 기준으로 매깁니다 (모순 한 곳 → 2, 모순 두 항목 이상 → 1).

1번에서 **모순 있음**을 골랐다면 보통 2점 이하, **없음**이면 보통 3점 이상입니다. 맞지 않게 고르면 도구가 한 번 확인합니다.

## 3. 일관성 (1–5) — 12개 항목이 한 사람으로 읽히는가

| 점수 | 기준 |
|---|---|
| 5 | 모든 항목이 한 사람의 이야기로 자연스럽게 이어진다 |
| 4 | 대체로 이어지지만 한 곳이 조금 겉돈다 |
| 3 | 두세 곳이 서로 잘 맞지 않는다 |
| 2 | 여러 항목이 서로 다른 사람처럼 읽힌다 |
| 1 | 한 사람으로 읽히지 않는다 |

앵커와의 관계가 아니라 **서사 항목끼리**의 관계를 봅니다. 예: 주말 일과에서는 매주 등산 동호회 활동이 중심이라고 했는데 직접 참여 이력에서는 동호회 활동을 해 본 적이 없다고 하면 일관성이 떨어집니다.

## 4. 개연성 (1–5) — 이런 사람이 서울에 실제로 있을 법한가

| 점수 | 기준 |
|---|---|
| 5 | 매우 그럴듯하다 |
| 4 | 그럴듯하다 |
| 3 | 흔하지 않지만 있을 수 있다 |
| 2 | 있을 법하지 않다 |
| 1 | 거의 있을 수 없다 |

**드문 사람과 불가능한 사람을 구분**하세요. 드물어도 있을 수 있으면 3점 이상입니다. 나이·성별·직업에 대한 **고정관념으로 판단하지 않습니다.**
**서사가 그리는 삶**을 평가합니다. 앵커의 조합 자체(예: 앵커가 10대인데 학력이 대학 졸업)는 이 점수에 넣지 않습니다.

## 5. 한국어 자연스러움 (1–5)

| 점수 | 기준 |
|---|---|
| 5 | 한국어 원어민이 쓴 자연스러운 글 |
| 4 | 대체로 자연스럽고 어색한 곳이 하나 |
| 3 | 어색한 표현이 여러 곳 있으나 뜻은 분명하다 |
| 2 | 번역투이거나 기계적인 문장이 많다 |
| 1 | 읽기 어렵거나 다른 언어가 섞여 있다 |

내용이 아니라 **문장**을 봅니다. 한자나 외국어가 섞여 있으면 2점 이하입니다. SNS·OTT·유튜브처럼 우리말로 널리 쓰는 말은 외국어로 보지 않습니다.
"정량 정보에 명시되지 않았으나"처럼 **글을 만든 과정이 드러나는 문장**은 모순이 아니라 자연스러움에서 감점합니다.

## 연습 문항

처음 **12개는 연습**입니다. 화면에 "연습"이라고 표시됩니다. 분석에 쓰지 않습니다. 위의 **헷갈리기 쉬운 경우**가 골고루 들어 있고, **저장하면 정답과 해설**이 나옵니다. 해설을 읽고 자기 판단과 다르면 이 지침서의 해당 부분을 다시 읽으세요. 연습이 끝난 뒤 지침서를 한 번 더 읽고 본 문항을 시작하는 것을 권합니다.

## 모두 끝난 뒤 — 합의 판정

두 평가자가 **모든 문항을 끝낸 뒤에만** 합의 판정이 열립니다. 두 사람의 판단이 크게 다른 문항 — **모순 여부가 다르거나, 앵커 부합 점수가 2점 이상 차이 나는 문항** — 만 나옵니다. 나머지 세 척도는 두 사람 점수의 평균을 쓰므로 맞추지 않습니다. 두 사람이 함께 앉아서:

1. **먼저 말하는 사람을 번갈아** 정합니다 (화면에 표시됩니다).
2. 각자 **근거 문장을 직접 짚어** 설명합니다.
3. **모순으로 합의하려면** 서사의 문장과 그것이 어긋나는 앵커 항목을 **함께 짚을 수 있어야** 합니다. 짚지 못하면 모순이 아닙니다.
4. 합의 칸은 **빈 칸에서** 시작합니다. 합의한 판정을 입력하고, **누가 의견을 바꿨는지와 그 이유**를 적습니다.
5. 합의가 안 되면 더 엄격한 쪽(모순 있음, 낮은 점수)으로 입력하고 「합의 불가」를 고릅니다.

처음 각자 매긴 점수는 지워지지 않고 그대로 보존됩니다.
